## 테스트 목록

#### 단위 테스트

- [x] Review, Done 상태인 태스크를 삭제하려고 하면 실패한다
- [x] To Do 상태의 태스크를 Review, Done으로 바꾸려면 실패한다
- [x] In Progress 상태의 태스크를 Done으로 바꾸려면 실패한다
- [x] Review 상태의 태스크를 To Do로 바꾸려면 실패한다
- [x] Done 상태의 태스크를 In Progress, Review으로 바꾸려면 실패한다

#### UI 테스트

- [x] To Do 상태인 태스크를 눌러서 다이얼로그를 열면 담당자에 '없음' 버튼이 존재한다
- [x] Review/Done 상태 태스크의 수정 다이얼로그에서 삭제할 수 없다

## 기능 목록

- [x] 태스크 카드를 클릭하여 수정/삭제 다이얼로그 열기
- [x] 태스크 관리 다이얼로그에서 To Do 상태일 때 담당자 목록에 "없음" 항목 출력
- [x] 태스크 수정
- [x] 태스크 삭제
    - To Do: 태스크 삭제 가능. 담당자 미지정 가능
    - In Progress: 태스크 삭제 가능. 담당자 지정 필수
    - Review: 태스크 삭제 불가능. 담당자 지정 필수
    - Done: 태스크 삭제 불가능. 담당자 지정 필수
- [x] 태스크가 수정/삭제되었을 때 스낵바를 출력
- [x] 태스크 수정/삭제 예외 처리

```
To Do
└─→ In Progress (작업 시작)

In Progress
├─→ To Do (다시 계획)
└─→ Review (리뷰 요청)

Review
├─→ In Progress (수정 필요)
└─→ Done (승인 완료)

Done
└─→ To Do (재작업)
```

    - 담당자 없음 버튼
