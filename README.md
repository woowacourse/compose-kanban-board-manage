# 칸반 보드 관리(수정)

## 2단계 - 칸반 보드 관리(수정) 구현할 기능 목록

### 도메인
- [x] 기존 태스크를 수정 또는 삭제할 수 있다.
- [x] Task가 가질 수 있는 `Review` 상태를 추가한다.
- [x] - [x] 상태별 태스크의 특징을 적용한다.
    - [x] To Do를 제외한 모든 상태는 담당자를 지정해야한다.
    - [x] To Do, In Progress는 삭제가 가능하지만 나머지는 불가능하다.
- [x] 상태는 전이 규칙을 가진다. 규칙은 아래와 같다. 규칙 외 전이는 불가능하다.
    - [x] To Do는 In Progress(작업 시작)로만 전이 가능하다.
    - [x] In Progress는 To Do(다시 계획) 또는 Review(리뷰 요청)로 전이 가능하다.
    - [x] Review는 In Progress(수정 필요) 또는 Done(승인 완료)로 전이 가능하다.
    - [x] Done 은 To Do로 전이 가능하다. (재작업)

### UI
- [x] 수정 Dialog를 생성한다.
  - [x] 태스크가 수정 불가능하면 바텀버튼이 사용가능하지 않다.
  - [x] 태스크가 삭제 불가능하면 바텀버튼이 사용가능하지 않다.
- [x] 태스크를 클릭하면 수정 Dialog가 표시된다.
- [x] 현재 Task의 상태에 맞게 수정 Dialog를 띄운다.
- [x] Review 상태의 Column을 보여준다.
- [x] 상태 변경의 시도가 있거나 Task를 변경할 시 Snackbar를 띄운다.
    - [x] Review 또는 Done 상태에서 태스크를 삭제하려고 할 때, "해당 상태에서는 태스크 삭제가 불가합니다." 메시지를 띄운다.
    - [x] 불가능한 상태 전이 시도를 할 시, "해당 상태로 옮길 수 없습니다" 메시지를 띄운다.
    - [x] 담당자를 지정하지 않고 In Progress로 전이 할 시, "담당자를 지정해야 상태를 옮길 수 있습니다." 메시지를 띄운다.
    - [x] 태스크가 수정되었을 때, "태스크가 수정되었습니다." 메시지를 띄운다.
    - [x] 태스크가 삭제되었을 때, "태스크가 삭제되었습니다." 메시지를 띄운다.
