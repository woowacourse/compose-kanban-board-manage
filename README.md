# 🚀 2단계 - 칸반 보드 관리(수정)

## 기능 목록

### 상태

- [x] Review 상태를 추가하고, 상태별 태스크의 특징을 적용한다.
    - [x] To Do: 태스크 삭제 가능. 담당자 미지정 가능
    - [x] In Progress: 태스크 삭제 가능. 담당자 지정 필수
    - [x] Review: 태스크 삭제 불가능. 담당자 지정 필수
    - [x] Done: 태스크 삭제 불가능. 담당자 지정 필수

### 다이얼로그

- [x] 태스크 카드 클릭 시 태스크 수정 다이얼로그가 노출된다.
    - [x] TODO 상태 선택 시, 담당자 `없음` 선택지가 노출된다.
    - [x] Review, Done 상태의 태스크는 삭제가 불가능하다.
- [x] 수정 완료 시, `태스크가 수정되었습니다.` 스낵바를 노출한다.
- [x] 삭제 완료 시, `태스크가 삭제되었습니다.` 스낵바를 노출한다.

### 드래그 앤 드롭(상태 전이)

- [x] 드래그앤드롭으로 상태 전환 시, 상태 전이 규칙이 적용된다.
    - [x] 규칙:
        - Todo -> InProgress(담당자 미지정 시, 불가능)
        - InProgress -> ToDo, Review
        - Review -> InProgress, Done
        - Done -> ToDo
    - [x] 정의되어있지 않은 상태 전이 시도 시, `해당 상태로 옮길 수 없습니다.` 스낵바를 노출한다.
    - [x] 담당자가 정의되지 않은 TODO를 InProgress로 전환 시, `담당자를 지정해야 상태를 옮길 수 있습니다.` 스낵바를 노출한다.
