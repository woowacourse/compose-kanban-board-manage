# 칸반 보드 관리(수정)

## 2단계 - 칸반 보드 관리(수정) 구현할 기능 목록

### 1. 태스크 카드를 클릭하여 태스크를 수정/삭제할 수 있다.
  - [x] 태스크 카드를 클릭하면 태스크 카드 생성 모달에 기존 태스크 값이 나타난다.
  - [x] 수정 버튼을 클릭하면 태스크 내용이 수정된다.
  - [x] 삭제 버튼을 클릭하면 태스크가 삭제된다.

### 2. 태스크가 수정/삭제되었을 때 스낵바를 노출한다.
  - [x] 태스크가 수정되었을 때 스낵바를 노출한다.
  - [x] 태스크가 삭제되었을 때 스낵바를 노출한다.

### 3. Review 상태를 추가하고, 상태별 태스크의 특징을 적용한다.
  - [x] Review 상태를 추가한다.
  - [x] 상태가 To Do일 경우, 담당자는 '없음', '다이노', '페임스' 중 선택할 수 있다.
  - [x] 상태가 To Do일 경우 태스크를 삭제할 수 있다.
  - [x] 상태가 To Do가 아닐 경우, 담당자는 '다이노', '페임스' 중 선택해야 한다.
  - [x] 상태가 In Progress일 경우 태스크를 삭제할 수 있다.
  - [x] 상태가 Review, Done일 경우 태스크를 삭제할 수 없다.

### 4. 태스크 상태 전이 규칙을 적용한다. 규칙에 적용되지 않은 상태 전이는 불가능하다.
  - [x] Review, Done 상태에서 태스크를 삭제하려고 할 때 삭제할 수 없음을 알리는 스낵바를 노출한다.
  - [x] To Do에서 Review, Done으로 상태 전이를 시도할 때 옮길 수 없음을 알리는 스낵바를 노출한다.
  - [x] In Progress에서 Done으로 상태 전이를 시도할 때 옮길 수 없음을 알리는 스낵바를 노출한다.
  - [x] Review에서 To Do로 상태 전이를 시도할 때 옮길 수 없음을 알리는 스낵바를 노출한다.
  - [x] Done에서 In Progress, Review로 상태 전이를 시도할 때 옮길 수 없음을 알리는 스낵바를 노출한다.
  - [x] To Do 상태에서 담당자를 지정하지 않고 In Progress로 전이할 때 옮길 수 없음을 알리는 스낵바를 노출한다.
