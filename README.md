# 칸반 보드 생성(프로젝트)


## 리팩토링
- [x] 함수형 프로그래밍을 활용하도록 리팩토링

## 기능 구현 사항

**1. 태스크 카드를 클릭하여 수정할 수 있다.**
- 비즈니스 로직
    - [x] 태스크 카드를 수정했을 시, 태스크를 업데이트 한다.
- UI 로직
    - [x] 태스크 카드를 클릭할 시, 태스크 카드 정보가 담겨있는 다이얼로그가 뜬다.
    - [x] 다이얼로그 하단 맨 오른쪽에는 수정 버튼이 있다.
    - [x] 태스크가 수정되었을 때 "태스크가 수정되었습니다."라는 스낵바를 노출한다.

**2. 태스크 카드를 클릭하여 삭제할 수 있다.**
- 비즈니스 로직
    - [x] 태스크 카드를 삭제했을 시, 태스크를 삭제한다.
- UI 로직
    - [x] 태스크 카드를 클릭할 시, 태스크 카드 정보가 담겨있는 다이얼로그가 뜬다.
    - [x] 다이얼로그 하단의 수정 버튼의 왼쪽에는 삭제 버튼이 있다.
    - [x] 태스크가 삭제되었을 때 "태스크가 삭제되었습니다."라는 스낵바를 노출한다.

**3. 상태에 Review를 추가한다.**
- 비즈니스 로직
    - [x] 상태에 Review를 추가한다.
- UI 로직
    - [x] 칸반 보드 화면에 Review 열을 추가한다.
    - [x] 모달 화면에 Review 버튼을 추가한다.

**4. 담당자는 To do 상태에서는 미지정할 수 있다.**
- 비즈니스 로직
    - [x] 담당자가 없는 경우에 대한 NONE을 생성한다.
    - [x] 담당자가 없는 것인지를 명시적으로 확인할 수 있는 함수를 생성한다.
- UI 로직
    - [x] 상태가 To do일 경우에는 담당자에 "없음" 란이 있다.
    - [x] 담당자가 없을 경우에 TaskCard에서는 담당자가 아예 표시되지 않는다.


**5. 상태별 각각 태스크 특징이 존재한다.**
- 비즈니스 로직
    - [x] To do 상태에서는 태스크 삭제가 가능하다.
    - [x] To do 상태에서는 담당자를 미지정할 수 있다.
    - [x] To do 상태에서는 In Progress로만 전이 가능하다.
    - [x] In Progress 상태에서는 태스크 삭제가 가능하다.
    - [x] In Progress 상태에서는 담당자가 지정된 상태여야 한다.
    - [x] In Progress 상태에서는 To do, Review로만 전이 가능하다.
    - [x] Review 상태에서는 태스크 삭제가 불가능하다.
    - [x] Review 상태에서는 담당자가 지정된 상태여야 한다.
    - [x] Review 상태에서는 In Progress, Done로만 전이 가능하다.
    - [x] Done 상태에서는 태스크 삭제가 불가능하다.
    - [x] Done 상태에서는 담당자가 지정된 상태여야 한다.
    - [x] Done 상태에서는 To do로만 전이 가능하다.
- UI 로직
    - [x] Review 혹은 Done 상태에서 태스크 삭제를 진행하려고 할 때, "해당 상태에서는 태스크 삭제가 불가합니다."라는 스낵바가 표시된다.
    - [x] 전이 불가능한 상태로 이동하려고 할때, "해당 상태로 옮길 수 없습니다."라는 스낵바가 표시된다.
    - [x] 담당자가 지정되지 않은 상태에서 To do에서 In Progress로 이동하려고 할 시, "담당자를 지정해야 상태를 옮길 수 있습니다."라는 스낵바가 표시된다.
