# 🚀 2단계 - 칸반 보드 관리(수정)

## 기능 구현 목록

1. Review 상태 추가
- [x] 상태에 review를 추가한다
- [x] kanbanboard에 review 상태 박스를 추가한다.
- [x] 다이얼로그 상태 선택 목록에 review 를 추가한다.

2. 상태별 태스크 특징 적용
- [x] 상태별 삭제 가능 여부 규칙을 정의한다. (To Do, In Progress만 삭제 가능)
- [x] 상태별 담당자 필수 여부 규칙 정의한다. (To Do만 담당자 미지정 가능)
- [x] 상태 전이 허용 규칙을 정의한다.
    - To Do → In Progress 
    - In Progress → To Do, Review
    - Review → In Progress, Done
    - Done → To Do
- [x] 허용되지 않은 상태 전이는 차단한다.

3. 태스크 수정 다이얼로그 생성  
- [x] DialogMode에 수정, 생성 모드를 추가한다.
- [x] DialogMode (CREATE, EDIT)에 따라 제목과 버튼 텍스트를 동적으로 변경한다
- [x] 담당자 선택지에 `없음` 옵션을 추가한다 (To Do 상태에서만 미지정 가능)

4. 태스크 카드 클릭 시  다이얼로그 노출
- [x] TaskCard의 onClick 이벤트에 다이얼로그 열기 로직을 연결한다
- [x] 수정 모드에서 기존 태스크 정보를 초기값으로 로드한다

5. 태스크 수정 기능 구현
- [x] 내용 수정 후 수정 버튼을 누르면 태스크가 수정된다
- [x] 수정 성공 시 스낵바 메시지를 노출한다 

6. 태스크 삭제 기능 구현
- [x] 태스크 삭제 버튼을 누르면 리스트에서 해당 태스크가 삭제된다.
- [x] review나 done 상태에서 태스크 삭제하려 하면 불가능하다는 스낵바 메시지를 노출한다.
- [x] 삭제 성공 시 스낵바 메시지를 노출한다 

7. 상태 전이
- [x] 불가능한 상태 전이를 시도할 때 차단하고 스낵바 메시지를 노출한다.
- [x] 담당자를 지정하지 않고 In Progress로 전이 시 담당자를 지정하라는 스낵바 메시지를 노출한다.
